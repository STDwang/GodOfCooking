# 《我是厨神》 · 3D 中华料理烹饪模拟与学习网页游戏

一款基于 **React + TypeScript + Three.js + Web Audio API** 打造的纯前端 3D 中式烹饪网页游戏。  
玩家将在充满烟火气的暖调中式厨房中，亲历 **「切菜备料 → 掌勺控火 → 调味出锅」** 的完整真实烹饪流程，在享受清脆解压的刀工切菜与颠勺锅气的同时，系统掌握经典国民中餐的家常做法、食材搭配与火候心法。

---

## 核心特色

- **沉浸式 3D 中式厨房场景**
  - 纯程序化构建暖棕方格瓷砖、水磨石灶台、红底福字挂饰、竹蒸笼、青花瓷碗、厚实年轮圆木砧板、中式菜刀与双灶铁锅燃气灶。
  - 全屏自适应视角，平滑兼容桌面端宽屏与移动端竖屏操作。
  - 零外部模型、零外部图片与音频文件依赖，所有 3D 材质贴图与音效均在浏览器内实时生成。

- **多向精准刀工与清爽视野**
  - 按食材种类与菜谱要求区分切菜方向与规格（例如嫩豆腐 3 向切 2cm 方块、土豆 2 向切 2mm 细丝、五花肉 2 向切 3cm 麻将块）。
  - 切菜开始前设有 **3 秒预备倒计时**，食材表面动态绘制金色完美切线，且隐藏手部模型确保刀刃与切线视野零遮挡。
  - 根据不同食材质感（软嫩、脆爽、紧实、肉类）实时合成差异化切菜音效，结束后给出精准刀工评分。

- **双手联动掌勺与分步限时评分**
  - 掌勺炒菜阶段启用 3D 双手联动动画：端碗倒菜、拧动燃气灶「关 / 文 / 中 / 旺」旋钮、依次投放调料、握柄颠勺配合锅铲翻炒，并伴随火焰强弱、油花滋啦与锅气升腾效果。
  - 顶部常驻简洁明了的**单步操作指引栏**与**分步倒计时**；系统从**火候档位切换、理想油温持续时长、投料油温与顺序时机、颠勺完成度**四个维度实时计分。
  - 步骤超时或锅温持续失控糊锅将触发「掌勺翻车」结算，支持「保留备料 · 重新掌勺」快速复盘重试。

- **三档贴近现实的烹饪难度体系**
  - 入口首页与选菜界面均可随时切换 **新手 / 高手 / 厨神** 三档难度，按真实做菜逻辑动态调整变量，帮助厨房小白平滑进阶。

- **内置「中华烹饪百科」**
  - 随时呼出，无需中断学习体验；支持关键词检索与个人收藏，涵盖完整克重勺量食谱、食材黄金搭配与中餐实用技法。
  - 百科内任意菜谱支持「立即开火试做」，一键进入厨房实操演练。

- **趣味附加模式：五秒狂切豆腐挑战**
  - 限时 5 秒高频三向切丁，体验极致连续落刀爽感与连击计数，记录个人最高刀数。

## 三档难度机制对比

| 难度档位 | 定位 | 切菜备料 | 调料与提示 | 火候与计时规则 |
| :--- | :--- | :--- | :--- | :--- |
| **新手** | 小白学做菜 | 刀数精简、刀刃扫动较慢、完美切线容差宽 | 每步精简为最多 2 种核心调料，高亮推荐下一步 | 自动匹配每步初始推荐火候、理想油温区间更宽、步骤限时充裕、糊锅速度慢 |
| **高手** | 家常掌勺 | 标准菜谱刀数与速度、标准切线精度 | 还原完整菜谱调料，保留推荐调料提示 | 需全程手动拧钮换火，限时考核投料时的油温时机与理想火候维持时长 |
| **厨神** | 极限锅气 | 刀数更密、扫动更快、切线判定更严苛 | 还原完整调料且**关闭调料高亮提示**，严格考核投料先后顺序 | 严苛每步倒计时、理想油温区间收窄、过热糊锅更快，且每步必须完成指定颠勺次数 |

## 中华烹饪百科内容

百科抽屉内置三大实用模块（支持关键词搜索与星标收藏，收藏记录持久化保存于本地）：

1. **经典食谱库（6 道）**：包含精准份量、备料/烹饪耗时、真实克重与勺量清单、4 步实操指南以及大厨私房秘诀。
2. **食材搭配指南（8 大类）**：覆盖嫩豆腐、猪五花肉、鸡胸/鸡腿肉、熟透番茄、黄心土豆、猪里脊肉、鸡蛋、牛里脊/牛腩的黄金搭档、处理技巧与烹饪避坑要点。
3. **烹饪心法与技巧（6 项）**：涵盖三向切丁法、先片后丝法、肉眼辨别三至七成油温、文/中/旺火与颠勺配合、鱼香/宫保/糖醋黄金碗汁比例，以及中餐放调料的先后铁律。

## 操作说明

- **切菜阶段**：
  - 点击画布任意区域或按 `空格键` 落刀，尽量对准食材表面的金色虚线获取「完美」评价。
- **掌勺阶段**：
  - 点击底部燃气灶火候按钮切换 **文火 / 中火 / 旺火**（联动 3D 旋钮与火焰强度）。
  - 按顶部步骤提示依次点击对应调料投入铁锅。
  - 点击 **「颠勺」** 按钮（或按 `空格键`）触发 3D 双手抛锅翻炒，降温并均匀裹汁。
- **进度保存**：
  - 玩家的难度偏好、各菜谱历史最高分、星级评价、五秒狂切最高记录及百科收藏条目均自动保存在浏览器 `localStorage` 中。

## 技术栈与项目结构

### 技术栈
- **前端框架**：React 19 + TypeScript + Vite
- **样式方案**：Tailwind CSS v4（暖白象牙与陶土朱红视觉体系）
- **3D 渲染**：Three.js（程序化几何体、动态 Canvas 切线贴图、物理质感 PBR 材质、软件 WebGL 帧率自适应）
- **音频引擎**：原生 Web Audio API（实时合成多质感切菜声、点火声、动态火力滋啦循环、倒料水花、颠勺呼啸及五声音阶成菜音效）
- **图标与动效**：Lucide React + Motion

## 本地运行与构建

### 环境要求
- Node.js 18+

### 启动步骤

```bash
# 1. 安装依赖
npm install

# 2. 启动本地开发服务器（默认监听端口 3000）
npm run dev

# 3. TypeScript 类型检查
npm run lint

# 4. 生产环境构建
npm run build
```
